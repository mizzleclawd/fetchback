## 2–3 sentence description (form field)

FetchBack is a multiplayer missing-pet search party on Convex: when a pet is
lost, volunteers claim territories on a realtime map while Firecrawl watches
shelter pages and an AgentMail inbox emails those shelters — every send
human-approved. Shelter replies with photos arrive by webhook, and OpenAI
vision through the Convex AI Gateway scores each as a possible match with
visible reasons. The owner — never the AI — confirms or rejects.

## Plain-text 100-word description (paste-ready)

FetchBack is a multiplayer missing-pet search party on Convex. Owners register pets and run practice drills; when a pet is lost, volunteers claim territories on a realtime map while Firecrawl watches shelter pages and an AgentMail inbox emails those shelters — every send human-approved. Shelter replies with photos arrive by webhook, and OpenAI vision through the Convex AI Gateway scores each as a possible match with visible reasons. The owner — never the AI — confirms or rejects. Every sponsor integration is real in production; the demo case is a labeled drill.
